# Human–AI Co-Designer — student project showcase

A static, accessible, mobile-responsive project case study for GitHub Pages. No build process, dependencies, analytics, or third-party scripts.

## Before publishing

1. Replace `[Student name]` and `[Year]` in `index.html`.
2. Replace the illustrative placeholder in the `feature` section with an actual screenshot. Suggested HTML:
   `<img src="assets/figma-plugin.png" alt="Figma plugin showing [describe actual accessibility issue, explanation and recommendation]" width="1600" height="900">`
   Add CSS: `.feature img{display:block;width:100%;height:auto;border-radius:16px;border:1px solid var(--line)}`. Remove the placeholder markup and placeholder caption.
3. Confirm the exact model name/version, technical descriptions and results with the student. The current page uses only the provided summary.
4. Confirm whether Brunel permits the proposed university identification and link from the official course page. Do not use Brunel logos without permission.
5. Optionally add a second screenshot or an approved link to a demo/repository. Do not publish proprietary code or credentials.

## Publish on GitHub Pages

1. Create a public GitHub repository, e.g. `hai-project-showcase` (preferably in a programme-managed account).
2. Upload `index.html`, `styles.css` and `assets/` to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. GitHub will show the published URL once deployed, typically `https://ACCOUNT.github.io/hai-project-showcase/`.
6. Ask the Brunel web team to add a short Student Project Spotlight teaser linking to that published URL.
